# مشروع تعريب لعبة Rematch الشامل ⚽🎮
### Rematch Arabic Localization (Full UI & In-Match Voice Callouts)

مشروع تعريب احترافي وغير تدميري للعبة كرة القدم **Rematch**، يشمل التعريب الكامل للقوائم وواجهة المستخدم (مع المعالجة الكاملة لاتجاه الحروف العربية من اليمين لليسار RTL)، بالإضافة إلى تعريب صوتي حماسي كامل لنداءات وتوجيهات اللاعبين التكتيكية داخل الملعب (In-Match Callouts / Quick Chat) باستخدام كوديك Wwise Opus الأصلي.

---

## 🌟 مميزات المشروع

- **تعريب القوائم وواجهة المستخدم (GameUI):**
  - ترجمة شاملة ودقيقة لكافة قوائم اللعبة، الإعدادات، والخيارات.
  - معالجة تشبيك الحروف العربية وضبط الترتيب من اليمين إلى اليسار (BiDi & Arabic Reshaping) لتظهر النصوص بشكل طبيعي وسليم تماماً داخل محرك اللعبة.
  - استبدال خيار اللغة بالقائمة ليظهر باسم "العربية" بشكل مباشر.

- **التعريب الصوتي الحماسي داخل المباراة (In-Match Callouts):**
  - **51 مقطعاً صوتياً حماسياً** يغطي كافة النداءات التكتيكية الـ 17 في الملعب (طلب التمرير، العرضية، القائم البعيد، القائم القريب، عكس اللعب، طلب الدعم، التحذيرات، التشجيع، الاعتذار...).
  - **تنويع واقعي في النبرات:** تم استخدام أصوات واقعية متنوعة بلهجات ونبرات تناسب أجواء مباريات كرة القدم (نبرة مصرية، سعودية، إماراتية) لتوزيعها على مختلف شخصيات اللاعبين في الفريق.
  - **مطابقة الكوديك الأصلي 100%:** تم تشفير الأصوات بصيغة **Wwise Opus** الأصلية (`0x3041` / 48,000 Hz Mono / 128 kbps) لضمان توافقها التام مع محرك الصوت Audiokinetic Wwise دون أي صمت أو أخطاء.
  - **حقن مزدوج:** تم تطبيق الأصوات على مساري **English(US)** و **Mandarin**، لتعمل الأصوات العربية سواء كانت لغة الصوت الافتراضية مضبوطة على الإنجليزية أو الصينية.

- **تثبيت آمن وغير تدميري (Non-Destructive Patching):**
  - **لا يتم تعديل أو استبدال ملفات اللعبة الأساسية نهائياً**؛ ملف الحزمة الأصلي للعبة (`Runtime-WinGDKClient.pak`) يظل سليماً بنسبة 100%.
  - تعمل كافة التعديلات عبر حزمة باتش إضافية خفيفة (`Runtime-WinGDKClient_99_P.pak`) مع ملف التوقيع الرقمي المعتمد (`.sig`).

---

## 🚀 طريقة التثبيت السريع (للاعبين)

1. حمّل ملفي الباتش الجاهزين من هذا المستودع:
   - `Runtime-WinGDKClient_99_P.pak`
   - `Runtime-WinGDKClient_99_P.sig`
2. انسخ الملفين وضعهما مباشرة داخل مجلد حزم اللعبة في المسار التالي:
   ```text
   C:\XboxGames\Rematch\Content\Runtime\Content\Paks\
   ```
3. شغّل اللعبة، واضبط الإعدادات:
   - **لغة النصوص / القوائم:** اختر اللغة الصينية (ستظهر باللغة العربية معربة بالكامل).
   - **لغة الصوت (Audio Language):** الإنجليزية أو الصينية (ستعمل النداءات العربية في الحالتين).
4. استمتع باللعبة مع التعريب الكامل والأصوات العربية الحماسية داخل الملعب!

## 🛠️ البناء والتطوير من المصدر (For Developers)

إذا أردت إعادة توليد الأصوات، تعديل الترجمة، أو إعادة حزم الباتش بنفسك:

### 1. المتطلبات:
- نظام تشغيل Windows 10 / 11
- Python 3.10 أو أحدث
- تثبيت المتطلبات عبر pip:
  ```bash
  pip install edge-tts
  ```

### 2. توليد الأصوات العربية:
يقوم السكربت بتوليد 51 مقطعاً صوتياً بنبرات وسرعات حماسية ملائمة لأجواء المباريات وحفظها كملفات WAV:
```bash
python generate_arabic_voices.py
```

### 3. تشفير الأصوات وحقن الباتش:
يقوم السكربت بتحويل ملفات الـ WAV إلى Wwise Opus (`.wem`) وحزمها مع ملفات ترجمة القوائم `GameUI.locres` ونشرها مباشرة لمجلد اللعبة:
```bash
python inject_arabic_voices.py
```
